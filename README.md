\# Object-Oriented Programming Lab



A collection of weekly lab exercises, practice programs, and implementations completed for the \*\*Object-Oriented Programming (OOP)\*\* course at the \*\*University of Engineering and Technology (UET), Lahore\*\*.



The repository primarily contains C# implementations covering fundamental and intermediate Object-Oriented Programming concepts, class design, object relationships, layered architecture, database connectivity, inheritance, polymorphism, and event-driven programming with Windows Forms.



> \*\*Note:\*\* This repository represents my coursework and learning progress throughout the OOP laboratory. Some implementations may follow the structure or requirements provided in the respective lab manuals and are not intended to represent production-ready software.

\## 🗓️ Weekly Overview



\### Week 2 — Classes, Objects \& Constructors



Introduces the basic building blocks of Object-Oriented Programming in C#.



Topics and exercises include:



\* Classes and objects

\* Object creation

\* Default constructors

\* Parameterized constructors

\* Copy constructors

\* Object/reference behavior

\* Basic class-based programs



Practice problems include examples such as:



\* Student-related classes

\* Transactions

\* Calculator

\* ATM

\* Student Management System

\* Product Management System

\* Sign Up / Sign In using classes



\---



\### Week 3 — Copy Constructors \& Class Behavior



Builds upon classes and constructors with greater emphasis on object manipulation and class behavior.



Topics include:



\* Copy constructors

\* Reference assignment vs. independent object copies

\* Member functions

\* Object behavior

\* Arrays and lists

\* `foreach` loops

\* Real-world class implementations



Practice exercises include simulations and class-based problems such as clock, game character, product, space mission, and library-related systems.



\---



\### Week 4 — Multiple Classes \& Class Interaction



Focuses on designing programs using multiple classes rather than placing all functionality into a single class.



Topics include:



\* Multiple classes

\* Member functions

\* Class responsibilities

\* Object interaction

\* Association between classes

\* Menu-driven programs

\* Real-world object modeling



The exercises include systems involving entities such as:



\* Students

\* Degrees

\* Products

\* Customers

\* Books

\* Members



\---



\### Week 5 — Static Members \& Layered Architecture



Introduces shared class-level members and a basic layered application structure.



Topics include:



\* Static attributes

\* Static functions

\* Instance vs. static members

\* Business Logic Layer (BL)

\* Data Layer (DL)

\* User Interface Layer (UI)

\* Menu-driven applications



A major application introduced in this lab is the \*\*University Admission Management System (UAMS)\*\*.



The repository also contains implementations involving the BL/DL/UI structure and exercises such as a Library Book Management System.



\---



\### Week 6 — Association, Aggregation \& Composition



Introduces relationships between objects and classes.



Topics include:



\* Association

\* Aggregation

\* Composition

\* "Has-a" relationships

\* Object ownership and lifetime

\* Designing interacting classes



The lab includes a structured \*\*Coffee Shop Management System\*\* and additional open-ended exercises involving systems such as workout tracking and other object-relationship scenarios.



\---



\### Week 7 — SQL Server \& Database Integration



Moves from storing application data in memory toward using a relational database.



Topics include:



\* SQL Server

\* SQL Server Management Studio (SSMS)

\* Database creation

\* Tables

\* Database connectivity from C#

\* SQL queries

\* Data Layer implementation

\* Persisting application data



The lab work includes the \*\*University Admission Management System (UAMS)\*\* with database functionality implemented through the Data Layer.



\---



\### Week 8 — Inheritance



Introduces inheritance as a mechanism for reusing and extending existing classes.



Topics include:



\* Base/parent classes

\* Derived/child classes

\* Code reuse

\* Inherited attributes and methods

\* `protected` members

\* Method overriding

\* Hierarchical class design



Exercises include examples involving:



\* Students

\* Hostelite and Day Scholar students

\* Bank accounts

\* Cars and rental systems

\* Other inheritance-based scenarios



\---



\### Week 9 — Polymorphism



Builds upon inheritance and introduces dynamic polymorphism.



Topics include:



\* Inheritance

\* Method overriding

\* `virtual` and `override`

\* Dynamic polymorphism

\* Base-class references

\* Runtime method dispatch



The exercises include inheritance and polymorphism problems involving:



\* `Circle` and `Cylinder`

\* Students and Staff

\* Animals such as Cats and Dogs

\* Shapes and area calculation



\---



\### Week 10 — Windows Forms \& Event-Driven Programming



Introduces graphical user interfaces using Windows Forms and the event-driven programming model.



Topics include:



\* Windows Forms

\* Form design

\* Controls

\* Text boxes

\* Buttons

\* Properties

\* Events

\* Click events

\* Form Load events

\* Event-driven programming

\* Connecting UI controls with C# logic



Exercises include simple event-driven applications as well as form-based functionality such as:



\* Message popups

\* Text-box interaction

\* Sign Up interfaces

\* Login-related functionality

\* Data update operations
